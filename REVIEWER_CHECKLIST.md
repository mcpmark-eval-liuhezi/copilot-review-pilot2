# Reviewer Checklist

Use these reminders when reviewing pull requests during the Copilot review pilot.

## Reminders

- [ ] Tests added or updated to cover the change
- [ ] Error handling verified (edge cases, failures, fallbacks)
- [ ] Documentation updated where behavior changes
- [ ] No unintended breaking changes to public APIs
- [ ] Logging and observability considered
- [ ] Security and secrets handling reviewed
